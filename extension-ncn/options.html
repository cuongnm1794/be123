Cài đặt lưu file

Chrome lưu file vào thư mục Tải xuống (Downloads) của bạn. Bạn chỉ định thư mục con bên trong Downloads (ví dụ để mở bằng VS Code).

F12 vẫn bị đá khi refresh? Mở tab mới → F12 (hoặc Undock DevTools) → sau đó mới vào URL. Guard giờ chạy ngay lúc tải trang; nếu DevTools đã mở sẵn trước khi vào, ít bị “lần đầu” hơn.
Gợi ý Windows: Đặt Chrome tải về D:\2025\Linh\namcaocnguyen\sources bằng cách bật “Lưu thành” ở trên, hoặc trong Chrome: Cài đặt → Tải xuống → Vị trí → chọn thư mục sources trong project này, rồi để Thư mục con trống hoặc ..
